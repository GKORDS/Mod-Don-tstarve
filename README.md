# Winona Global Catapult Mod

Mod สำหรับเกม Don't Starve Together ที่เพิ่มระยะควบคุม Winona Catapult และ Winona Remote ให้ไกลสุดทั่วทั้งแผนที่

## คุณสมบัติ
- เพิ่มระยะการมองหาและยิงของ Winona Catapult ให้ครอบคลุมทั้งแผนที่
- ปรับ Winona Remote ให้สามารถควบคุมป้อมได้จากทุกที่

## การติดตั้ง
คัดลอกโฟลเดอร์ม็อดนี้ไปไว้ในโฟลเดอร์ `mods` ของเซิร์ฟเวอร์หรือไคลเอนต์เกม Don't Starve Together
